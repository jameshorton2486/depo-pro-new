# Supported local release environment

The qualified first-release boundary is one reporter using one local Windows workstation and one Depo-Pro API process. Deposition evidence storage must be a local, non-synchronized folder. The runtime reports its exact product version, Node runtime, API binding and storage root in Administrator Settings.

Not qualified in this release: multiple concurrent API processes, shared/network storage, OneDrive/Dropbox-managed evidence storage, multi-user access, cloud artifact storage, email delivery, or distributed locking.

Chrome is the primary qualified browser. Hardware microphone, foot-pedal, sustained-recording, Microsoft Word and physical-printing behavior require qualification on the actual release workstation before real deposition use.
