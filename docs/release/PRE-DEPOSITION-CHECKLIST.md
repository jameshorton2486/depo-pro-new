# Pre-deposition checklist

- Confirm Administrator Settings shows the expected version and local evidence-storage root.
- Confirm adequate free disk space and a completed, independently verified backup of active work.
- Confirm the intended microphone/audio interface and optional pedal are selected and functioning.
- Run a short test recording; stop it, play it back, and confirm audio is intelligible.
- Confirm case, witness, jurisdiction, reporter/officer, appearances and remote-location facts.
- Confirm network availability and transcription-provider credentials if live transcription will be used.
- Close duplicate Depo-Pro windows and do not run a second API process against the same storage.
- Keep an independent recording/fallback procedure available until the workstation's sustained-capture qualification is complete.
